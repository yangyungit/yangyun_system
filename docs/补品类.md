# 补品类

头条事件落地后按顺序走，目标 30 分钟内出可交易清单。

1. **定格子**：这次卡的是哪个商品的哪一环？（商品 + `STAGES` 里的一个值）
2. **查在不在**：这一格在 `RIGID` 里有没有？有 → 直接看载体，流程结束。没有 → 继续
3. **找载体，按四类各问一遍**（这一步是机械的，不要临场发挥）：
   - 有没有期货合约？（yfinance 试 `XX=F`）
   - 有没有期货滚动 ETF？——按发行人找，运费是 Breakwave、农产品是 Teucrium、宽基是 Invesco/USCF
   - 有没有实物信托？——贵金属和铀才有
   - 有哪些纯 play 股票？——要求主营占比高，别拿多元化集团充数
   - **美股找完必须再走一轮海外**：澳洲 `.AX`（矿）、日本 `.T`（设备/航运）、韩国 `.KS`（造船）、欧洲 `.AS`/`.PA`/`.DE`/`.MI`/`.OL`/`.CO`/`.SW`/`.L`（工业/电缆/气体）、印尼 `.JK` 与马来 `.KL`（锡镍）、加拿大 `.TO`、香港 `.HK`、A 股 `.SS`/`.SZ`
   - **A 股纯 play 先查有没有 H 股**，两个都收、标清通道，别替自己做通道决定
   - 已有 ADR 的品类要拿本土上市对比一次日均成交额再决定用哪个——`LYC.AX` 是 `LYSDY` 的 16 倍
4. **验活验容量**：拉近 60 日日均成交额。低于 500 万美元标「观察」，同时算「按 20% 日均成交量建仓，我的目标仓位要几个交易日」
5. **定对照组**：同期 `PDBC` 加该商品的宽基。没有对照组就分不清是品类独有还是商品普涨
6. **写回 `rigid_list.py`**，六个字段填齐（`commodity` / `stage` / `stuck` / `stuck_entities` / `respond` / `carriers`），缺一个不许提交
